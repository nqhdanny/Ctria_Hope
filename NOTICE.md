## 2. Base APK used to build

Ctria Hope is produced by decompiling a released Citra MMJ APK, injecting patches, and
repacking — it is not compiled from the C++ tree. To make that reproducible, the exact
base package is identified by hash:

| Field | Value |
|---|---|
| File | Citra MMJ release APK (`versionName 3eb22034a`) |
| package / versionCode | `org.citra.emu` / 3932 |
| SHA-256 | `00ae1fca3e5831cb383ad64a31cc0e9d4213f89296803ec1b733b5feeb82bba4` |

`dec/` in the build directory is the output of `apktool d -s <that APK>`, with
`classes.dex` left untouched. All modifications are in the patched smali, the patched
manifest/resources, and an appended `classes2.dex`. The SHA-256 of each released build is
published in the corresponding release notes.

## 4. Original work in this repository (GPL-2.0)

Everything below was written for this project and is released under GPL-2.0-or-later,
matching the upstream license.

| Path | What it is |
|---|---|
| `patch/HingeHelper.java` | Dual-screen geometry: computes both screen rectangles from real display metrics, aligns the top screen to the hinge |
| `patch/SettingsSkin.java` | Wallpaper-derived palette; re-skins Settings pages, dialogs and the in-game running-settings dialog |
| `patch/BundledGames.java` | First-run provisioning of `Games/`, `theme/`, calibrated control layout |
| `patch/StorageGate.java` | All-files-access gate for `targetSdk 34` |
| `patch/patch_*.py` | Idempotent smali / manifest / resource injectors |
| `patch/skins_design.py`, `patch/skins_panel.py`, `patch/gen_theme.py` | Programmatic renderer for the eight panel skins (39 files each) |
| `patch/build.sh` | The complete build pipeline |
| `themes/*.zip` | The rendered output of the above; all artwork generated by code |

**Artwork:** the panel skins contain no third-party imagery. Bezel gradients, button
recesses, the camera bar, speaker grille and the `Fun in Hope` silk print are all drawn
procedurally by `skins_panel.py`. The silk print deliberately replaced the console
wordmark that earlier internal builds carried, so that no skin reproduces a Nintendo mark.

**Fonts:** none bundled; text is rendered with the device's system font at build time.
