# Политика конфиденциальности — Ctria Hope

**Обновлено: 13 ноября 2026 г.**
**Область применения:** Ctria Hope (`com.ctriahope.emu`), версия 1.4.3 и новее.
В более ранних сборках использовалось имя пакета `org.citra.emu` — политика для них
идентична.

## Коротко

Ctria Hope **не собирает никаких данных**. Нет учётной записи, нет входа, нет аналитики,
нет рекламы, нет отчётов о сбоях, нет отслеживания. Приложение **не выполняет никаких
автоматических сетевых запросов** — оно даже не проверяет обновления. Всё, что вы
загружаете в эмулятор, остаётся на вашем устройстве.

| Вопрос | Ответ |
|---|---|
| Собираете ли вы персональные данные? | Нет |
| Используете ли аналитику или рекламные SDK? | Нет |
| Передаёте ли данные третьим лицам? | Нет |
| Можно ли пользоваться офлайн? | Да, полностью — ничего не загружается само |
| Нужны ли мой e-mail или номер телефона? | Нет |
| Отправляются ли данные во время игры? | Нет |

Поскольку персональные данные не собираются, нам нечего хранить, продавать, раскрывать
или удалять по запросу. Это соответствует требованиям Федерального закона № 152-ФЗ
«О персональных данных»: обработка персональных данных не осуществляется, поэтому
уведомление оператора и локализация баз данных неприменимы.

## Что приложение хранит на устройстве

Всё находится в папке `citra-emu/` в общей памяти устройства, и только там:

| Данные | Назначение | Как удалить |
|---|---|---|
| `Games/` — добавленные вами игры | То, во что вы играете | Удалить папку |
| `config/` — настройки эмулятора | Разрешение, шейдеры, управление, тема | Очистить данные приложения |
| `saves/`, `states/`, `sdmc/` — сохранения и снимки состояния | Ваш прогресс | Удалить папку |
| `theme/` — скины корпуса | Внешний вид | Удалить папку |
| `log/` — журналы эмулятора, если включены | Диагностика на вашем устройстве | Удалить папку |

Ни один из этих файлов приложением никуда не отправляется. При удалении приложения папка
`citra-emu/` остаётся на месте, чтобы вы не потеряли сохранения; удалите её вручную, если
она не нужна.

## Разрешения и зачем они нужны

Ctria Hope запрашивает только те разрешения, которые действительно использует ядро
эмулятора. Любое из них можно запретить — игры запустятся, просто соответствующая
функция не будет работать.

| Разрешение | Зачем |
|---|---|
| **Доступ ко всем файлам** (`MANAGE_EXTERNAL_STORAGE`) | Начиная с Android 11 общая память скрыта от приложений без этого разрешения. Эмулятору нужно читать игры, которые вы положили в `citra-emu/Games`, и записывать сохранения рядом. Без него список игр пуст. Доступ ограничен файлами, которые эмулятор читает и пишет; ничего не сканируется, не индексируется и не передаётся. |
| `READ_/WRITE_EXTERNAL_STORAGE` | То же самое для Android 10 и ниже. |
| **Камера** | Используется только эмулируемой камерой 3DS: игра, которой нужен вид с камеры, получает изображение с камеры телефона. Кадры передаются игре в памяти. Приложение не делает, не хранит и не отправляет фотографии. |
| **Микрофон** | Используется только эмулируемым микрофоном 3DS для игр, которые его слушают. Звук передаётся игре в памяти, не записывается и не передаётся. |
| **Вибрация** | Тактильная отдача. |
| **Интернет**, **состояние сети / Wi-Fi** | Только для сетевой игры — локальной или онлайн, и только когда её запускаете **вы**. В фоне ничего не загружается. |
| **Ярлык на главном экране** | Позволяет вынести ярлык отдельной игры на рабочий стол. |

## Сетевая активность, точно

- **Никаких автоматических запросов.** Приложение не проверяет обновления, не отправляет
  статистику и не обращается ни к одному серверу само по себе. Обновления приходят из
  магазина, из которого вы установили приложение — поэтому встроенная проверка обновлений,
  унаследованная от апстрима, была удалена.
- **Сетевая игра.** Если вы настроите сервер комнаты и войдёте в комнату, игровые данные
  передаются участникам и **выбранному вами** серверу. По умолчанию выключено и происходит
  только по вашему действию. Своих серверов мы не держим и ничего не получаем.
- **Больше ничего.** Нет фоновой синхронизации, нет пингов, нет телеметрии, нет
  сборщика отчётов о сбоях.
- **Открытие исходного кода.** На экране «О приложении» есть кнопка «Source code»,
  открывающая этот репозиторий в браузере. Это обычная ссылка, она срабатывает только по
  нажатию и не передаёт данных о вас. Она существует потому, что GPL-2.0 требует, чтобы
  исходный код распространяемого бинарника был доступен.

## Компоненты третьих сторон

Приложение построено на открытом коде (Citra / Citra MMJ, GPL-2.0-or-later) и включает
две игры домашнего производства (homebrew) под лицензиями MIT. Тексты лицензий
поставляются внутри APK и доступны в разделе «О приложении → Licenses». Ни один из этих
компонентов не собирает данные.

Приложение **не содержит** ROM-файлов, таблиц ключей, системных шрифтов, образов NAND или
прошивки консоли.

## Дети

Приложение не собирает данные ни о ком, включая детей, и не содержит рекламы, покупок или
социальных функций. Ограничений по возрасту нет.

## Ваши права

Поскольку персональные данные не собираются и не хранятся, у нас нет данных, которые можно
предоставить, исправить или удалить по запросу. Все файлы, создаваемые приложением, лежат
на вашем устройстве, и вы полностью контролируете их.

## Изменения политики

Если политика изменится, новая редакция будет опубликована в этом репозитории с новой датой
обновления. Существенные изменения будут отражены в описании обновления приложения.

## Где прочитать политику внутри приложения

Полный текст доступен офлайн на устройстве: **Настройки → О приложении → Privacy policy**
(на английском, русском и китайском). Тот же текст поставляется внутри APK, поэтому он
доступен без сети и не может стать нерабочей ссылкой.
