# 把游戏放进 Ctria Hope

三句话说完：

1. **装完就有 6 个游戏**，首次启动自动释放，不用下载。
2. **加自己的游戏 = 复制一个文件**到 `citra-emu/Games`。
3. **只有加密的商业游戏需要密钥**，而密钥只能来自你自己的主机。

---

## 一、支持的格式

| 格式 | 是什么 | 要密钥吗 |
|---|---|---|
| `.3dsx` | 自制软件标准格式，体积小、从不加密 | 不需要 |
| `.cia` | 安装包格式，**不需要真安装**，直接加载 | 看内容：自制软件不用，商业游戏要 |
| `.3ds` | 卡带镜像（CCI），零售卡带每个分区都是 AES-CTR 加密 | 需要（除非已解密） |

> **记一句**：点开是**纯黑屏、没声音、也不报错**，九成是"加密镜像 + 没有密钥"，见第四节。

## 二、去哪里找

唯一判断标准：**项目有没有写许可证**。写了 MIT / GPL / CC0 / Zlib 的，随便下载、随便留；什么都没写的，默认保留所有权利，不要到处传。

| 渠道 | 说明 |
|---|---|
| **Universal-DB** `db.universal-team.net` | 3DS 自制软件索引库，每条标了版本、许可证、下载直链 |
| **GitHub** 话题 `3ds-homebrew` | 看 Releases 里的 `.3dsx` / `.cia`，仓库侧栏能看到许可证 |
| **itch.io** 标签 `3ds` | 独立作者小游戏，部分是 `3dsx` |
| **GBAtemp / 4PDA** | 论坛发布帖，冷门作品多；4PDA 是俄语社区 |

不要用"ROM 全集"站点：除了法律问题，这类站点是恶意文件重灾区，商店审核也会直接判分发盗版内容。

## 三、怎么放进去

只有一个目录：

```
/sdcard/citra-emu/Games/
```

在文件管理器里显示为 **内部存储 → citra-emu → Games**。

1. 手机上下载，或从电脑用 USB 传过去。
2. 移动到 `citra-emu/Games`。保留扩展名；中文名可以，但不要带 `? * : " < > |`。
3. 回到应用下拉刷新；没反应就清后台重开。

如果这个文件夹不存在，先打开一次应用，它会建好整个目录树。

> **列表为空、还弹了文件访问提示**：请允许"管理所有文件"。不给这个权限，应用只看得到自己的私有目录，永远发现不了你放进 `citra-emu/Games` 的文件。授权后它会自动重建目录并释放内置游戏。

## 四、密钥与字体（只有加密游戏需要）

**来源**：3DS 零售数据用 AES-CTR 加密，解密要 KeyX/KeyY，KeyY 由每张卡带的唯一 ID 派生。这些密钥没有任何合法公开渠道，只能从你拥有的主机上提取（社区通用工具 GodMode9 的官方文档里有步骤）。能拿到游戏文件的人，本来就能拿到密钥 —— 两者出自同一次提取。

**位置**：

```
/sdcard/citra-emu/sysdata/
├─ aes_keys.txt          解密商业游戏
├─ cbf_std.bcfnt         系统字体（文字显示空白时才需要）
├─ cbf_zh-Hans-CN.bcfnt  可选，简体中文
└─ cbf_ko-Hang-KR.bcfnt  可选，韩文
```

`sysdata` 不存在就自己新建。文件名大小写敏感，必须完全一致。

| 现象 | 缺什么 | 放什么 |
|---|---|---|
| 黑屏、无声音、无报错 | 密钥 | `aes_keys.txt` |
| 能进游戏，文字全是空白方块 | 系统字体 | `cbf_std.bcfnt` |
| 中文/韩文显示成 `?` | 对应语言字体 | `cbf_zh-Hans-CN.bcfnt` 等 |

自制软件 `.3dsx` 两样都不需要 —— 所以内置 6 个游戏在"全新安装、零密钥、零字体"下照样能跑，已实测。

## 五、实测能跑的游戏

在 **HUAWEI Pura X Max**（内屏 1828×2584）上逐个点开确认过，全部开源许可。

| 游戏 | 许可证 | 体积 | 备注 |
|---|---|---|---|
| **2048**（随包） | MIT | 133 KB | 数字合并，触屏 |
| **T-Rex**（随包） | MIT | 1.3 MB | Chrome 小恐龙 |
| **Cookie Collector** | CC0 | 197 KB | 放置类，按 X 攒饼干 |
| **Block Blast** | Zlib | 214 KB | 方块消除，触屏带音效 |
| **Trogdor Reburninated** | MIT | 2.5 MB | 横版动作；**音频需另放数据目录** |
| **Craftus Reloaded** | MIT + CC BY-SA（贴图） | 387 KB | 3D 沙盒，最吃性能 |

两个**没跑起来**的，省得你浪费时间：

- **Balatro3DS**（GPL-3.0，17 MB `.3dsx`）：能加载，但停在作者自己的 *NO GAME* 画面，需要它附带的资源目录，单文件版不自洽。
- **Bottomless Block Barrage**（GPL-3.0，`.3ds`）：双屏全黑。这类 `.3ds` 通常加密。

Trogdor 要声音和存档，把整个 `Trogdor-RB` 文件夹放到：

```
/sdcard/citra-emu/sdmc/3ds/Trogdor-RB/
```

不放也能玩，只是没声音、不能存档。

## 六、故障对照

| 现象 | 处理 |
|---|---|
| 新游戏不出现 | 重启应用；确认在 `citra-emu/Games` 而不是 `Download`；确认没还是 `.zip` |
| 点开黑屏 | 缺 `aes_keys.txt`，或该 `.3dsx` 需要真机 CFW 环境 |
| 文字空白 | 缺 `cbf_std.bcfnt` |
| 能进但卡 | 分辨率倍率降到 1×；Craftus 这类 3D 本身重 |
| 存档没了 | 存档在 `citra-emu/sdmc`，卸载前先备份整个 `citra-emu` |
| 权限提示一直弹 | 系统设置 → 应用 → Ctria Hope → 权限 → 允许所有文件访问 |

## 七、边界

本指南只做一件事：把你**合法拥有**的游戏放进模拟器。应用不提供、不下载、不内置任何 ROM、密钥或主机固件；随包的 6 个游戏都是开源原创作品，许可全文随 APK 分发，也在 [`licenses/`](../licenses/) 里。

没有主机也没有卡带？那就玩随包游戏和社区 homebrew —— 这条路完全够用，且不需要任何密钥。
