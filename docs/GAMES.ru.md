# Как добавить игры в Ctria Hope

Три факта закрывают почти все вопросы:

1. **Шесть игр уже внутри.** Они распаковываются при первом запуске — скачивать ничего не нужно.
2. **Добавить свою игру = скопировать один файл** в `citra-emu/Games`.
3. **Ключи нужны только для зашифрованных коммерческих образов**, и взять их можно только со своей консоли.

---

## 1. Поддерживаемые форматы

| Формат | Что это | Нужна таблица ключей |
|---|---|---|
| `.3dsx` | Стандартный формат homebrew. Маленький, никогда не шифруется. | Нет |
| `.cia` | Формат установочного пакета. **Устанавливать не нужно** — загружается напрямую. | Только если внутри коммерческая игра |
| `.3ds` | Образ картриджа (CCI). Каждый раздел в картридже зашифрован AES-CTR. | Да, если образ не расшифрован |

> **Простое правило:** если игра открывается **чёрным экраном, без звука и без ошибки** — это почти всегда зашифрованный образ без таблицы ключей. См. раздел 4.

## 2. Где искать игры

Единственный критерий: **указана ли лицензия**. MIT, GPL, CC0, Zlib — скачивайте, храните, передавайте. Лицензии нет — все права защищены, не распространяйте.

| Источник | Описание |
|---|---|
| **Universal-DB** — `db.universal-team.net` | Каталог homebrew для 3DS: версия, лицензия и прямая ссылка на скачивание |
| **GitHub** — тема `3ds-homebrew` | Смотрите Releases, файлы `.3dsx` / `.cia`; лицензия указана в боковой панели репозитория |
| **itch.io** — тег `3ds` | Небольшие игры независимых авторов, часть в формате `3dsx` |
| **GBAtemp / 4PDA** | Темы релизов на форумах; 4PDA — русскоязычное сообщество |

Не пользуйтесь сайтами «полных коллекций ROM». Помимо юридических проблем, это распространённый источник вредоносных файлов, а магазины приложений считают распространение пиратского контента основанием для автоматического отказа.

## 3. Куда положить файл

Один каталог:

```
/sdcard/citra-emu/Games/
```

В файловом менеджере это **Внутренняя память → citra-emu → Games**.

1. Скачайте файл на телефоне или перенесите по USB.
2. Переместите в `citra-emu/Games`. Расширение сохраняйте; кириллица в имени работает.
3. Вернитесь в приложение и потяните список вниз для обновления. Если ничего не произошло — закройте приложение в списке недавних и откройте снова.

Если папки ещё нет, запустите приложение один раз — оно создаст структуру каталогов.

> **Если список пуст и приложение просит доступ к файлам** — разрешите **«управление всеми файлами»**. Без этого оно видит только свой приватный каталог и никогда не найдёт то, что вы положили в `citra-emu/Games`. После разрешения оно пересоздаст каталоги и распакует встроенные игры.

## 4. Ключи и шрифты — только для зашифрованных игр

**Откуда.** Данные розничных картриджей 3DS зашифрованы AES-CTR; для расшифровки нужны KeyX/KeyY, причём KeyY вычисляется из уникального ID картриджа. Легальных публичных источников этих ключей не существует — только ваша собственная консоль (порядок действий описан в документации стандартной утилиты сообщества). У кого есть файл игры, у того есть и ключи: и то и другое получается в одном процессе дампа.

**Куда положить:**

```
/sdcard/citra-emu/sysdata/
├─ aes_keys.txt          расшифровка коммерческих игр
├─ cbf_std.bcfnt         системный шрифт (если текст пустой)
├─ cbf_zh-Hans-CN.bcfnt  опционально, китайский
└─ cbf_ko-Hang-KR.bcfnt  опционально, корейский
```

Если `sysdata` нет — создайте вручную. Имена файлов чувствительны к регистру.

| Симптом | Чего не хватает | Что положить |
|---|---|---|
| Чёрный экран, тишина, без ошибки | таблица ключей | `aes_keys.txt` |
| Игра идёт, но весь текст — пустые квадраты | системный шрифт | `cbf_std.bcfnt` |
| Китайский/корейский текст как `?` | шрифт языка | `cbf_zh-Hans-CN.bcfnt` и т. п. |

Homebrew `.3dsx` не нуждается ни в том, ни в другом — поэтому шесть встроенных игр работают на чистой установке без ключей и шрифтов. Проверено.

## 5. Игры, проверенные на устройстве

Проверялись по одной на **HUAWEI Pura X Max** (внутренний экран 1828×2584). Все — с открытой лицензией.

| Игра | Лицензия | Размер | Примечание |
|---|---|---|---|
| **2048** (в комплекте) | MIT | 133 КБ | Слияние чисел, сенсор |
| **T-Rex** (в комплекте) | MIT | 1,3 МБ | Динозаврик из Chrome |
| **Cookie Collector** | CC0 | 197 КБ | Кликер/текстовая, кнопка X |
| **Block Blast** | Zlib | 214 КБ | Головоломка с блоками, звук |
| **Trogdor Reburninated** | MIT | 2,5 МБ | Экшен; **для звука нужен каталог данных** |
| **Craftus Reloaded** | MIT + CC BY-SA (текстуры) | 387 КБ | 3D-песочница, самая тяжёлая |

Две игры, которые **не** запустились, чтобы вы не тратили время:

- **Balatro3DS** (GPL-3.0, 17 МБ `.3dsx`) — загружается, но останавливается на экране автора *NO GAME*: нужен каталог ресурсов, одиночный файл не самодостаточен.
- **Bottomless Block Barrage** (GPL-3.0, `.3ds`) — оба экрана чёрные. Такие `.3ds` обычно зашифрованы.

Для звука и сохранений Trogdor положите папку `Trogdor-RB` целиком в:

```
/sdcard/citra-emu/sdmc/3ds/Trogdor-RB/
```

Без неё игра тоже идёт — но без звука и без сохранений.

## 6. Типичные проблемы

| Симптом | Что делать |
|---|---|
| Новая игра не появляется | Перезапустите приложение; проверьте, что файл в `citra-emu/Games`, а не в `Download`; что это не `.zip` |
| Чёрный экран при запуске | Нет `aes_keys.txt`, либо `.3dsx` требует реальной консоли с CFW |
| Пустой текст | Нет `cbf_std.bcfnt` |
| Идёт, но тормозит | Уменьшите масштаб разрешения до 1×; 3D-игры вроде Craftus тяжёлые сами по себе |
| Пропали сохранения | Сохранения в `citra-emu/sdmc`; перед удалением приложения скопируйте весь каталог `citra-emu` |
| Постоянно всплывает запрос доступа | Настройки → Приложения → Ctria Hope → Разрешения → доступ ко всем файлам |

## 7. Границы

Это руководство об одном: как поместить в эмулятор игры, которые **принадлежат вам legally**. Приложение не содержит, не скачивает и не поставляет ROM, таблицы ключей или прошивку консоли. Шесть встроенных игр — оригинальные open-source проекты; тексты лицензий поставляются внутри APK и лежат в [`licenses/`](../licenses/).

Если консоли и картриджей нет — играйте во встроенные игры и community homebrew. Этого достаточно, и ключи для них не нужны.
