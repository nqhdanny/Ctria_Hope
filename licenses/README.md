## The license of this project

Ctria Hope is GPL-2.0-or-later, inherited from Citra. Concretely, for anyone
redistributing a built APK:

1. **§1** — ship the full license text and keep the copyright notices.
2. **§3** — accompany the binary with the corresponding source, or a written offer to
   provide it. The corresponding source is this repository at the matching tag; the base
   APK hash and upstream commit are recorded in [`../NOTICE.md`](../NOTICE.md).
3. **§6** — add no further restrictions. In particular: no "you may not fork this", no
   extra permission grants, no end-user agreement that narrows GPL rights.
4. **§2** — if you modify it, license the modified files under GPL-2.0 as well.

Nothing here is optional. Shipping the binary without the source offer is the single most
common way a GPL Android app ends up non-compliant.
